Space Ship

Pilot a ship through escalating enemy waves. Chain kills to boost your score multiplier, grab weapon upgrades, and take down the boss every fifth wave.

▶ Play now View source

Play in your browser

The game runs in your browser via WebAssembly (pygbag). Might take a few seconds to load. Press P to pause and the arrow keys to move.

Not loading? The WebAssembly build is generated by GitHub Actions — give it a moment on first visit, or run it locally.

Features

A clean, deterministic engine under the hood, and a classic arcade feel on top.

🛡

3 enemy types

Drones drift down, strafers fire aimed bullets, and kamikazes hunt you down.

🔒

Boss waves

A tanky boss appears every 5 waves to test your aim and your dodging.

🔥

Weapon upgrades

Collect pickups to go from a single shot to a three-way spread.

⭐

Combo scoring

Chain consecutive kills for a score multiplier of up to x4.

✨

Power-ups

Weapon upgrades, shields, and extra lives drop from destroyed enemies.

⚙️

Clean engine

Fixed-timestep loop, scene manager, and validated settings — fully tested.

Run it locally

Prefer the desktop build? You need Python 3.9+.

git clone https://github.com/1998x-stack/space_ship.git
cd space_ship
pip install -r requirements.txt
python main.py
